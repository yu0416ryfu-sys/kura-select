## 1. 背景

### 1.1 きっかけとなった2つの入力

**(a) Grok による評価**
> KuraSelect は実体験ベースの深みや写真レビューが薄いため、感情的な共感や滞在時間を伸ばす要素が少ない

**(b) 外部事例（`docs/外部事例/` の3ファイル）**

X に投稿されていた「Claude × 楽天放置アフィで月24万円」という記事と、そこで公開されていたプロンプト2本。

| ファイル | 内容 |
|---|---|
| `0.紹介.txt` | 本体記事。実績提示 → 楽天アフィが有利な理由 → 4STEP手順 → 月次推移 → 失敗談 → PDF配布でLINE誘導 |
| `1.放置に向いているジャンル抽出.txt` | ジャンル選定プロンプト |
| `2.比較記事作成.txt` | 比較記事生成プロンプト（本計画が参照するのはこれ） |

**この事例の信頼性について（レビュー時の前提）**

- 収益額（月24万円）と月次推移は**検証不能な自己申告**であり、記事の着地点は LINE 登録誘導＝リード獲得である。数字は根拠として採用しない。
- 一方、**構成テンプレート自体**は一般的なレビュー記事の型として妥当性があり、KuraSelect に欠けている要素を指摘する材料としては使える。
- 本計画は「事例の数字を信じて追随する」ものではなく、「構成の欠落を GA4 実測で確認し、埋める」ものとして設計している。

### 1.2 事例プロンプト（`2.比較記事作成.txt`）の構成

```
1. 読者がいま困っている場面の描写
2. この記事が向いていない人（先に外す）
3. 選ぶときに見るべき基準を3つ
4. 比較表
5. 商品ごとのレビュー（良い点・気になる点・向いている人）
6. 使い方別のおすすめ
7. まとめ

ルール
・すべての商品を良いと書かないこと。合わない場面を必ず書くこと
・数字と具体的な使用場面を入れること
・体験の一言を自然に混ぜること
・「絶対」「必ず」「誰でも」の保証表現は使わないこと
・効果や結果の断定はしないこと
・整いすぎた文章にせず、文の長さに揺らぎを作ること
```

## 3. 提案する変更

事例の7構成のうち、**①「読者が困っている場面の描写」と②「この記事が向いていない人」の2つだけ**を追加する。

### 3.1 採用する要素

| # | 要素 | 配置先 | 根拠 |
|---|---|---|---|
| ① | 冒頭の場面描写（辞書的定義を置き換え） | 本文冒頭 | 離脱が起きるのはページ上部。エンゲージ率に直接効く |
| ② | 「この記事が向いていない人」セクション | 本文冒頭直後 | 実装コスト最小。先に外すことで信頼を得る定石 |

### 3.2 今回は採用しない要素（と理由）

| 要素 | 見送る理由 |
|---|---|
| ⑤ `cons` を「買ってから後悔するポイント」へ書き換え | **価値は高いが後回し**。商品ごとの作業で 63記事 × 約7商品と重い。効くのはページ下部＝既に読んでいる読者で、離脱率にはほぼ効かない。①②の効果を確認してから投資する |
| ⑥ 使い方別のおすすめの強化 | 既存の「用途別のおすすめ」と重複。①②の効果測定を濁す |
| 「体験の一言を混ぜる」 | **採用不可**。§6.2 参照 |
| 「数字を入れる」 | **採用不可**。CLAUDE.md §5.0.1 に抵触。§6.1 参照 |

### 3.3 対象記事の選定：`wet-tissue-comparison`

**選定理由**

1. **測定可能な唯一の記事**。105PV/28日 は2位以下の1.7倍。2週間で約50セッション確保できる
2. **伸びしろが離脱側にある**。滞在125秒に対しエンゲージ率51%＝約半数が即離脱している。①②が効く位置と一致する
3. **測定凍結の対象外**（§7.1 参照）

**却下した候補**

- `kitchen-paper`（エンゲージ率76%）: 既に良好で伸びしろが薄い
- `dish-detergent`（滞在23秒）: headroom は最大だが 26PV では2週間で方向性すら読めない
- `fabric-softener` / `laundry-detergent`: 数値浄化タスクが未了で、改修と浄化が同時になり交絡する（§7.2）

### 3.4 対象記事の現状

- **title**: `ウェットティッシュおすすめ10選【2026年】除菌・コスパを1枚単価で比較`
- **publishedAt**: 2026-05-01 / **updatedAt**: 2026-07-30（`update-products` による自動更新）
- **本文構成**: `選び方ガイド` → `迷ったらこの3つ`(表) → `アルコール/ノンアルコールの違い`(表) → `用途別のおすすめ` → `コスパ比較のポイント` → `まとめ`
- **本文冒頭（変更対象）**:
  > テーブルの拭き取り、手指の除菌、子どもの手口拭きなど、ウェットティッシュは日常生活で幅広く使われます。毎日何枚も使うものだからこそ、**1枚あたりのコスト**で比較しましょう。
- **掲載商品**: 10点（VINDA / レック / 子育て日和 / シルコット×2 / アイリスオーヤマ / エリエール×2 ほか）。アルコール・ノンアルコール・手口ふきが混在

### 3.5 変更のドラフト（レビュー対象）

**変更1: 冒頭の置き換え**

現状の辞書的定義を、購入前に迷いが発生する具体的な場面の描写に差し替える。方向性：

> 買ったウェットティッシュが手口拭きに使えないと気づくのは、たいてい子どもの口を拭こうとした瞬間です。パッケージの「除菌」表示だけで選ぶと、アルコールタイプと手口ふき用が入れ替わっていても気づきにくい。ウェットティッシュは1枚単価の差が積み上がる消耗品ですが、単価より先に「用途が合っているか」で外すほうが失敗が減ります。

- 数値・商品名・効果効能の断定を含めない
- 「除菌力が高い」等の薬機法に触れうる表現を避け、用途適合の話に寄せる

**変更2: 「この記事が向いていない人」の新設（`## 選び方ガイド` の直前）**

> ## この記事が向いていない人
>
> 次のいずれかに当てはまる方は、この記事の比較表はあまり役に立ちません。
>
> - **赤ちゃんのおしりふきを探している方** — 用途が異なります。[おしりふき・手口ふきの比較](/articles/baby-wipes-comparison/) をご覧ください
> - **手指の消毒剤を探している方** — ウェットティッシュは拭き取りが主目的の製品です。医薬部外品の消毒剤とは分類が異なります
> - **収納場所を決めていない方** — 大容量パックは1枚単価が下がりますが、置き場所が確保できないと使い切る前に乾燥が進みます

- 内部リンクは `src/lib/site.ts` の `url()` ヘルパー経由で解決する（CLAUDE.md §6）
- 3項目のうち2つは既存記事への導線になるため、回遊にも寄与する見込み

**変更しないもの**

- frontmatter（`products[]`、`title`、`description`、`faqs`）は一切触らない
- 既存の本文セクション（`迷ったらこの3つ` 以降）は保持
- OGP 画像は title 不変のため再生成不要（ただしビルドでは自動実行される）

## 5. 測定設計

### 5.1 指標と比較方法

| 項目 | 内容 |
|---|---|
| 主指標 | `engagementRate`（対象 pagePath） |
| 副指標 | `averageSessionDuration`、`screenPageViews` |
| ベースライン | 2026-07-03 〜 07-30（PV105 / 125秒 / 51%） |
| 測定期間 | デプロイ日 〜 2026-08-14（約2週間） |
| 取得方法 | GA4 MCP `ga4_report`（dimensions: `pagePath`） |

### 5.2 判定基準

- **成功**: エンゲージ率が 51% → 58% 以上（+7pt 以上）
- **失敗**: 51% を下回る
- **判定保留**: 上記の間。1〜2週間延長して再判定

### 5.3 測定上の限界（レビュー時に認識してほしい点）

- **`averageSessionDuration` はセッション単位の指標であり、ページ単位の滞在時間ではない**。当該記事が入口となったセッション全体の長さを見ているため、回遊が増えると滞在も伸び、①②の効果と区別できない
- **母数が小さい**。2週間で約50セッション。得られるのは統計的有意差ではなく**方向性のみ**
- 8月上旬は Track C の CTA 再判定（〜08-10）も走る。対象記事が異なるため直接の干渉はないが、サイト全体の変動が乗る可能性はある
- Google のアルゴリズム変動は制御不能（2026年6月の変動事例あり。`docs/ACCESS_ANALYSIS_2026-07-27.md` 参照）

## 6. 制約条件（既存ルールとの整合）

### 6.1 CLAUDE.md §5.0.1「本文に数値を書かない（単一ソース原則）」

数値の真実は frontmatter `products[]` の1か所のみ。本文と `faqs[].answer` に価格・単価・レビュー件数・年間コスト・順位を書いてはならない。

→ **本計画の追加文は数値を一切含まないため抵触しない**。`scripts/lib/article-body-lint.ts` のガードも通過する見込み（`pnpm test` で確認する）。

### 6.2 「体験の一言を混ぜる」を採用しない理由

Grok の指摘（実体験の薄さ）に対する最も直接的な打ち手だが、**実際に使用していない商品について体験を書くことは虚偽記載であり、ステマ規制および景表法の直撃対象**となる。外部事例の筆者自身も末尾で「使ってない商品について体験を書くのは、単純に嘘になる」と明記している。

実体験の不足を偽装せずに埋める代替案（本計画のスコープ外・将来検討）:

1. **実際に使用している商品だけ、その旨を明示して書く**。日用品サイトのため該当商品は少なくないはず。実物写真もこの範囲なら現実的
2. **楽天レビューの集約を出典付きで使う**。「レビューで繰り返し挙がる不満」は一次体験ではないが検証可能な事実で、法的に安全。`reviewCount` / `rating` は API 取得済み
3. **失敗シナリオを寸法・条件レベルまで具体化する**。体験の代わりに「どういう条件で外すか」で深さを出す

### 6.3 `update-products` との干渉

`scripts/update-products.mjs` が書き換えるのは `price` / `rating` / `reviewCount` / `capacity` / `offers` のみ（同ファイル 130-135行目で確認）。`pros` / `cons` / `features` / `recommendedFor` および**本文は一切書き換えない**。

→ 本計画の本文編集は毎週月曜の自動更新と**完全に無干渉**。将来 §3.2 の `cons` 書き換えに進む場合も、手書き内容は保持される。

### 6.4 その他

- 薬機法: 「除菌力が高い」等の効果断定を避け、用途適合とコスパの話に寄せる（CLAUDE.md §11）
- 断定表現: 「最安」「No.1」は根拠なしに使わない
- 内部リンク: `url()` ヘルパー経由（直書きは GH Pages で 404）

## 8. レビューで判断してほしい点

1. **対象記事の選定は妥当か。** 測定可能性（105PV）を優先し `wet-tissue` を選んだが、headroom 最大の `dish-detergent`（滞在23秒 / 26PV）を選ぶ判断もありうる。母数不足を許容してでも効果の大きさを見にいくべきか
2. **スコープを①②に絞る判断は妥当か。** `cons` 書き換え（§3.2）を最初から含めたほうが、記事1本あたりの改善幅が大きく判定しやすいという反論はありうる
3. **§3.5 のドラフト文面**は、薬機法・景表法・KuraSelect のトーンとして適切か。特に「向いていない人」で3商品カテゴリを名指しで外している点
4. **判定基準 +7pt は妥当か。** 母数50セッションに対して厳しすぎる／緩すぎる可能性
5. **測定期間2週間で足りるか。** 8/10 の Track C 判定に合わせて期間を揃える選択肢もある
6. **実体験の不足（§6.2 の代替案1〜3）**について、本計画とは別に着手すべきものがあるか。Grok の指摘の核心はここであり、①②はその代替ではなく別の穴を埋めるものである点をどう扱うか

## 9. 想定されるリスク

| リスク | 影響度 | 対応 |
|---|---|---|
| エンゲージ率が悪化する | 中 | 1記事のみのため revert は容易。git で即座に戻せる |
| 母数不足で判定不能に終わる | **高** | 発生確率が最も高い。その場合は期間を4週間に延長し、それでも読めなければ「効果測定不能」と結論して次の施策へ移る |
| 「向いていない人」で読者を外しすぎ、離脱が増える | 中 | 3項目のうち2項目は既存記事への導線であり、サイト内回遊として回収される設計 |
| 追加文が `article-body-lint` に引っかかる | 低 | `pnpm test` で事前検出 |
| Google 変動が測定に乗る | 中 | 制御不能。判定時に GSC の表示回数推移を併せて確認する |
